# Fix My Code Challenge

This directory contains my solutions for the Holberton "Fix My Code" challenge.

## Files

- `0-fizzbuzz.py`: Python FizzBuzz. Prints numbers from 1 to n. Multiples of 3 print Fizz, multiples of 5 print Buzz, multiples of both print FizzBuzz.
- `1-print_square.js`: JavaScript square printer.
- `2-sort.rb`: Ruby sorting script.
- `3-user.py`: Python User class.
- `4-delete_dnodeint`: C function that deletes a node from a doubly linked list.

## Usage

    ./0-fizzbuzz.py 89
